# 已修复的问题

本篇列出 Spawner 修复的引擎缺陷。大多数修复在 Spawner 启用时始终生效，没有 INI 开关。

## 崩溃修复

### 异常过滤器

顶层异常过滤器会修复一组已知崩溃特征，而不是直接结束游戏：

| 故障地址 | 原因 | 恢复方式 |
|---|---|---|
| `0x5D6C21` | 地图缺少路径点 90 | 从 `0x5D6C36` 继续 |
| `0x7BAEA1` | `DSurface::GetPixel` | 从 `0x7BAEA8` 继续，EBX 清零 |
| `0x7BC806` | `BlitPlain` 路径 | 从 `0x7BC80F` 继续 |
| `0x535DBC` | 键盘命令类 | 从 `0x535DCE` 继续，调整 ESP |
| `0x55E018` 后的 `0x000000` | 尤里复制人控制建筑后按快捷键 | 从 `0x55E018` 继续，调整 ESP |

其他异常按正常流程处理。

### 单项崩溃修复

- `ObjectClass::Mark` 崩溃。
- `TriggerTypeClass::ComputeCRC` 遇到空房屋类型。
- `TechnoClass::GetMyOwner` 遇到空俘虏管理器。
- `TechnoClass::Revealed` 遇到空房屋。
- `TechnoClass` 状态更新遇到空科技对象。
- 增援放置遇到空房屋。

## 不同步修复

### 地块属性过期

`CellClass::RecalcAttributes` 根据地块与覆盖物计算地表类型与可通行性。
多条代码在移除覆盖物后没有重新计算，导致地表类型过期，
寻路结果在玩家之间分歧。Spawner 在以下操作后重新计算：

- 移除木箱，单人与多人路径都处理。
- 移除旗帜。
- 建造藤蔓洞。
- 桥梁摧毁与桥梁受损。

### 飞机阴影

绘制飞机阴影时临时将高度设为 0，这会在地图上放置并拾起飞机，
从而触发地块重新计算。只有能看到飞机的玩家会执行这段逻辑，
因此在战争迷雾下地表类型会分歧。Spawner 将阴影绘制期间的
三次高度修改改为空操作。

### 隐形单位

后置动画路径只对视觉正常的对象执行。隐形对象会因归属不同产生不同结果。
Spawner 对隐形对象跳过该动画。

### 迷雾检查

跳过 `SessionClass` 中基于迷雾的反作弊检查，避免不同步。

### SSE 浮点状态

部分显卡驱动在 `SetDisplayMode` 内创建 D3D9 设备时会破坏 MXCSR 寄存器。
舍入模式被改变后，`100%` 会被解析成 `0.99999994` 而不是 `1.0`，
进而让移动速度不同步。Spawner 会在以下时机修复 MXCSR：

- `SetDisplayMode` 返回后。
- 对局开始时。
- 每个逻辑帧开始时。

只有舍入模式确实被改变时才修复，并且最多记录十次日志。

## 大地图支持

`IsoMapPack5` 解码器有固定缓冲区大小。大型高细节地图会超出限制，
左下角被填成高度 0 的空地块。Spawner 将解码上限从 640 x 400
提高到 1024 x 768，缓冲区上限从 512000 提高到 1572864 字节。

## 小地图摄像机修复

当地图小于屏幕分辨率时，战术摄像机与雷达可能显示地图外区域或出现画面异常。
Spawner 会：

- 将战术位置限制在真实地图矩形内。
- 用黑色填充地图外区域。
- 将雷达视图矩形限制在雷达范围内。

## 网络修复

- 使用 `GetAdaptersAddresses` 枚举本机 IPv4 接口与广播地址，
  不再依赖旧的主机名查询。
- 使用隧道或玩家端口与监听端口不同时，强制端口匹配。

## 界面与输入修复

- 移除"需要鼠标"检查，避免在部分系统上无法启动。
- 空格键不再退出等待玩家窗口。
- 连续按类型选择键不再掉帧。
- Tab 打开战役简报，输入锁定时也能使用。
- 游戏输入锁定时忽略 Esc 抬起事件，但影片仍可用 Esc 跳过。
- 加载界面不再为未捕获鼠标时无效的光标操作等待。
- Spawner 启用时跳过计分界面按钮动画。
- 加载期间不绘制标题界面背景。

## 文本与字体修复

CnCNet 构建把 `game.fnt` 替换为 `cncnet.fnt`；实体 ID 长度检查改为记录
开发者警告，而不是弹出消息框。

这些修复自动生效。除 `DisableGameSpeed`、`DisableChat`、`AllowChat`、
`AllowTaunts`、`DisableEdgeScrolling` 以及文末所述的视频键之外，
没有单独关闭某一项修复的 INI 键。
